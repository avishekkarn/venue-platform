# Project Documentation

This directory contains the seven canonical documents of the project.

| Document | Purpose |
|----------|---------|
| `PRODUCT.md` | What the product is, every feature, flow, screen, loop |
| `DECISIONS.md` | 53 locked decisions across 15 categories |
| `SYSTEM.md` | Layers, data model, APIs, lifecycles, security |
| `BUILD.md` | Coding standards, testing, verification, task/report formats |
| `ROADMAP.md` | 10 phases, 224 tasks, dependencies |
| `PROGRESS.md` | Living project log, append-only |
| `DESIGN.md` | Frontend design specification, tokens, components |

## How to Read

Start with `PRODUCT.md`. Then read `DECISIONS.md` for the reasons. Then `SYSTEM.md` for the shape. Then `BUILD.md` for the method. Then `ROADMAP.md` for the plan. Then `PROGRESS.md` for the history. Then `DESIGN.md` for the visual language.
